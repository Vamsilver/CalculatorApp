# Калькулятор (Windows Forms)

Учебный проект на C#/.NET 9, выполненный по кейс-задаче № 3.

## Возможности

- четыре арифметические операции: сложение, вычитание, умножение и деление;
- последовательные вычисления с сохранением промежуточного результата;
- ввод десятичных и отрицательных чисел, удаление последнего символа и очистка;
- защита от деления на ноль, переполнения и некорректного ввода;
- история выполненных вычислений;
- сохранение истории в `.txt` и последующая загрузка;
- светлая и тёмная цветовые схемы.
- обычный и инженерный режимы;
- инженерные функции: степени, корни, факториал, логарифмы, модуль, `floor`, `ceil`, `exp` и `mod`;
- тригонометрические, обратные и гиперболические функции с режимами `DEG/RAD`;
- вложенные скобки, память `MC/MR/MS/M+/M−`, вторичные функции `2nd` и формат `F-E`;
- меню дополнительных функций, включая случайное число и преобразование `DEG ↔ DMS`.

## Запуск

1. Откройте `CalculatorApp.sln` в Visual Studio 2022.
2. Назначьте `CalculatorApp` запускаемым проектом.
3. Нажмите `F5`.

Либо выполните в терминале:

```powershell
dotnet run --project CalculatorApp/CalculatorApp.csproj
```

## Проверка

Проект собирается командой:

```powershell
dotnet build CalculatorApp.sln
```

Рекомендуемые ручные сценарии: `2 + 3 = 5`, `10 − 4 = 6`, `6 × 7 = 42`, `8 ÷ 2 = 4`, `2 + 3 × 4 = 20` (последовательное вычисление), `5 ÷ 0` (сообщение об ошибке).
